Conectar con Firebase

Esta plantilla ya tiene las operaciones para crear, leer, editar y eliminar productos. Para activarlas, abre firebase.js y pega la configuración de tu proyecto Firebase.

  1. Crea un proyecto en Firebase Console.
  2. Agrega una aplicación web y copia la configuración.
  3. Activa Cloud Firestore en modo de producción y crea la base de datos.
  4. Activa Authentication con correo y contraseña (recomendado para proteger el inventario).

Antes de publicar, configura reglas de seguridad de Firestore. No uses reglas abiertas en producción.
